# Simplified portfolio guide

This is a simplified version of the original portfolio, keeping all four pages and their content.

- `index.html`: Home and featured projects
- `projects.html`: Projects and category filters
- `about.html`: Bio, skills, and experience
- `contact.html`: Contact details and email form
- `css/style.css`: Layout, colors, and responsive design
- `js/script.js`: Menu, theme, filters, copy email, and email form

Edit the HTML text and `TODO` comments to add your information. The contact form opens an email app; it does not send messages directly.

CSS is organized by section. The layout uses basic Grid/Flexbox and two media queries. The original README is retained for the class planning requirement; update its answers to match this simpler version.
