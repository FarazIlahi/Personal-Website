PART 2: DESIGN (Answer ALL questions)

1. What overall style will best represent you?
A simple, modern design with a slightly creative, game-inspired theme. I want it to look professional enough for employers but still reflect my personality.
2. What color scheme will you use and why?
A dark color scheme with dark blue and gray backgrounds, light text, and green accents. I prefer darker themes, and the accent colors help important buttons and sections stand out.
3. What fonts will you use for headings and body text?
Simple sans-serif fonts for readability, with a monospace font for smaller labels or technical details to give the website a programming-inspired look.
4. How will your design reflect your personality or field?
The website will have a subtle game-inspired style because I enjoy gaming and programming. The dark colors and organized layout also reflect my interest in technology.
5. What layout will your homepage follow?
The homepage will start with a navigation bar, followed by an introduction about myself, a section highlighting my skills and projects, and links to explore the rest of the website.
6. How will you organize project sections visually?
Projects will be displayed using cards arranged in a grid. Each card will contain a project name, short description, and relevant technologies or links.
7. Will the site be mobile-friendly? How will you ensure responsiveness?
Yes. I will use CSS Flexbox, Grid, and media queries so that sections and project cards adjust to smaller screens.
8. What visual hierarchy will guide visitors?
Large headings will draw attention to important sections, followed by smaller descriptions and buttons. The main focus will be on introducing myself and directing visitors toward my projects.
9. How will consistency be maintained across pages?
All pages will share the same CSS file, navigation bar, colors, fonts, and button styles.
10. How will accessibility be considered?
I will use readable font sizes, good contrast between text and backgrounds, descriptive links, and proper HTML elements. I will also make sure the website works on different screen sizes.
11. Will you use icons, images, or illustrations? Why?
Yes, but only where necessary. I may use icons for social links and images for projects to make the website more visually interesting without overcrowding it.
12. What portfolio websites inspired your design?
My design is inspired by modern developer portfolios and gaming interfaces. I wanted something simple and organized, but with a little more personality than a traditional professional website.

PART 3: INTERACTIVITY (Answer ALL questions)

1. What interactive elements will your site include (navigation menus, buttons, forms)?
Navigation links between pages, buttons to view projects, project filtering buttons, a light/dark mode toggle, and a contact form.
2. Will your site include a contact form? How will it work?
Yes. The contact page will have a simple form where visitors can enter their name, email, and message. JavaScript will handle basic validation and feedback. Since the website is hosted on GitHub Pages, it will not have a backend to actually send messages.
3. What JavaScript features will you implement?
I will use JavaScript event listeners, DOM manipulation, and class toggling to add features such as switching between light and dark mode, filtering projects, and handling the contact form.
4. How will users receive feedback from interactions?
Buttons will visually respond when clicked, the website colors will change when switching themes, and the contact form will display feedback when submitted.
5. How does interactivity improve the user experience?
Interactivity makes the website easier and more enjoyable to use. Visitors can navigate between pages, filter projects to find what interests them, and switch between light and dark themes depending on their preference.
